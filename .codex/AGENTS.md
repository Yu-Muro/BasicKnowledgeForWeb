# Codex設定・Skillsの保守

共通規約は [ルートAGENTS.md](../AGENTS.md) に従う。このファイルは `.codex/` 配下の保守に適用する。

- Skillの作成・更新は `skill-creator` を使い、name/description、実装との整合、参照先を確認する。
- Pluginの配布済みSkillsをここにコピーしない。ローカルSkillsにはこのリポジトリ固有の契約と手順を残す。
- `.codex/config.toml` の既存変更を尊重し、削除済みMCPを復活させない。設定の存在とツールの接続成功を区別する。
- 分担が有益な調査・レビューはサブエージェントへ切り出す。小さな修正はメインで完了してよい。モデルは現在の設定を基本とし、変更が必要な場合だけ利用可能なモデルと権限を確認する。
- 同じファイルに複数のwriterを置かない。親は返却結果を原資料・実装・差分と照合する。
- 指示の構造審査と実際のタスク実行評価を区別する。大きな挙動変更は `empirical-prompt-tuning` の対象とし、未取得の指標を推測で埋めない。
